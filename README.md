Arduino Uno ve Arduino Nano kullanarak nRF24L01+ modülleri arasında çift yönlü kablosuz veri iletişimi sağlayan test projesi.

**Özellikler**
- Çift yönlü TX/RX haberleşmesi
- Her saniye otomatik veri gönderimi
- Paket sayacı
- SSD1306 OLED ekran desteği
- RF24 kütüphanesi desteği
- Arduino Uno ve Nano uyumluluğu
